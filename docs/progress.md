## Ratings display and enrichment, 2026-10-10
- Done: `wp guam-restaurants match-ratings --source=<google|yelp|foursquare>` matches restaurants by name similarity and distance (150 m around the OSM coordinates). Clear matches (confidence ≥ 0.8 and 0.1 ahead of the next candidate) store the source ID plus `gr_<source>_match_confidence`; confidence 0.5 to 0.8, or two close candidates, go to `gr_review_queue` as `match_conflict` with the source ID and our scores only. Field masks: Google `places.id,places.displayName,places.location` (Text Search Pro), Foursquare `fsq_place_id,name,latitude,longitude` (Pro). Yelp search has no field masks.
- Done: `GuamRestaurants\Core\get_ratings( $restaurant_id )` returns, per source, rating, review count, source name, required attribution, link to the source page, and review text as returned. Storage per docs/data-sources.md §9: Google and Foursquare fetched live per view, never stored; Yelp kept in a transient (`gr_rating_yelp_{id}`) for at most 24 hours, filled by a twice-daily WP-Cron refresh (`guam_restaurants_refresh_ratings`) and never fetched during a page view. No `rating_snapshots` table.
- Done: REST endpoint `GET /wp-json/guam-restaurants/v1/restaurants/{id}/ratings` (`Cache-Control: no-store`, `DONOTCACHEPAGE`); block `guam-restaurants/ratings` and shortcode `[guam_restaurant_ratings]` print a placeholder that `assets/ratings/ratings.js` fills, so page caches never hold ratings.
- Done: cost control, zero cost by default (Sanjay, 2026-10-10: "run this for free"). Every call is counted per billing unit for the month and is free until 90% of the source's free allowance (Google Text Search Pro 4,500, Place Details Enterprise 900, Enterprise + Atmosphere 900; Foursquare Pro 450; Yelp and Foursquare Premium 0). `GUAM_RESTAURANTS_RATINGS_RUN_CAP_USD` and `GUAM_RESTAURANTS_RATINGS_MONTHLY_CAP_USD` default to $0, so no paid call is made: runs stop, Google falls back to rating-only and then hides until next month, and Foursquare ratings and Yelp never show. `discover` counts against the same Text Search allowance. Commands print free and billable request counts first.
- Decided: no combined or average score (needs Sanjay's approval of a labeled formula). Yelp is never shown next to other ratings (Yelp API Terms §5(c)): any source list that mixes Yelp with others drops Yelp, so Yelp needs its own block in a separate page section. Yelp is hidden until Yelp's official star images are configured (`GUAM_RESTAURANTS_YELP_ASSETS_URL`). Foursquare keeps its 10-point score instead of stars.
- Decided: **no rating trend chart.** A trend chart needs stored rating history, and no source allows it: Google forbids caching ratings at all (Maps ToS §3.2.3(a)), Yelp caps storage at 24 hours (API Terms §5(a)), and Foursquare pay-as-you-go forbids server caching (Usage Guidelines). See docs/data-sources.md §7 Q3. A trend chart could only use first-party data (visitor highlights or editorial scores).
